# Application assets

[icons/](icons/) holds DUNE branding/icons used by packaging, executable
resources and generated documentation. For example, the
[Doxygen configuration](../doc/Doxygen/Doxyfile.in) uses `icons/dune.png`.

These are build/presentation inputs, not vehicle task code or configuration.
The separate [www/images](../www/images/) directory belongs to the onboard web
dashboard.
