# Runtime configuration

INI files assemble vehicle-specific task graphs on top of the
[source modules](../src/README.md). They are runtime configuration, not build
dependency declarations.

Sections such as `[Sensors.GPS]` name tasks; `/suffix` distinguishes instances.
`Enabled` selects execution profiles (for example `Simulation` or `Never`),
`Entity Label` names an instance for other tasks, and the remaining keys map to
parameters declared in its C++ constructor. `[Require relative/path.ini]`
composes configuration fragments. See [auv/basic.ini](auv/basic.ini) for a
composition example and [auv/simulator.ini](auv/simulator.ini) for replacement
sensor/vehicle tasks.

| Section | Contents and relationships |
| --- | --- |
| [common/](common/) | Shared transport, maneuver, plan, address and simulation-model definitions. |
| [auv/](auv/) | Underwater-vehicle control, navigation, maneuvers, supervision and simulation fragments. |
| [asv/](asv/) | Surface-vehicle configurations. |
| [uav/](uav/) | Aerial-vehicle configurations and autopilot/control integration. |
| [hardware/](hardware/) | Board/device settings, including controller platforms and acoustic modems. |
| [simulation/](simulation/) | Simulation scenarios; [uav.ini](simulation/uav.ini) includes UAV defaults and selects simulator settings. |
| [testing/](testing/) | Task and scenario configurations, including replay and plan fixtures. |
| [development/](development/) | Development/experimental setups rather than a universal vehicle default. |
| [wmm/](wmm/) | World Magnetic Model data supporting geomagnetic calculations. |

[Main](../src/Main/README.md) accepts configuration directory/file, profiles
and vehicle-name options. The parser is
[DUNE::Parsers::Config](../src/DUNE/Parsers/Config.hpp); task management resolves
instances and entity labels. Shared IMC addresses can be regenerated by the
[IMC tooling](../programs/generators/README.md).

Configurations may reference real serial ports, radios, power boards and
actuators. Inspect their included files and enabled profiles before running
them; a simulation file is not permission to operate hardware.
